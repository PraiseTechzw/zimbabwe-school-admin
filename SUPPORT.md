# Support

Zimbabwe School Admin is currently in an early foundation stage. The most useful support requests are specific, reproducible, and clear about the school workflow being improved.

## Before opening a request

Please search the existing issues and read the README and contributing guide. Confirm that the problem still occurs on the latest `main` branch, and remove all real personal or school data from examples and screenshots.

## What to include

A useful request normally includes the operating system, Node.js and pnpm versions, the command or workflow being used, the expected result, the actual result, and a short reproduction path. For UI issues, include the screen size and a redacted screenshot when appropriate. For database or server issues, include the relevant error message without secrets.

## Request categories

| Need | Best channel |
| --- | --- |
| Bug or reproducible product issue | GitHub issue with reproduction steps |
| Feature or workflow proposal | GitHub issue describing the school process and desired outcome |
| Setup question | GitHub issue with environment details and command output |
| Security vulnerability | Follow [`SECURITY.md`](SECURITY.md); do not post exploit details publicly |
| Conduct concern | Contact maintainers privately as described in [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) |

Please be patient and constructive. Maintainers may ask for a minimal reproduction or additional context before investigating.
